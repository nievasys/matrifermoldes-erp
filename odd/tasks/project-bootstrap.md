# project-bootstrap

Bootstrap the Matrifer ERP repository from zero: git repo, SvelteKit 3 scaffold, local database,
project structure, commit conventions and ERS implementation tracking. No MVP features (phase 0 spike not passed yet).

## Specs

- S1. "Quiero que arranques el proyecto desde 0. Levanta todo y decime que es lo que tengo que configurar."
- S2. "levanta el repo, setea una base de datos, ordena el proyecto."
- S3. "quiero que crees un .md de commits en español y usando las convenciones siempre."
- S4. "quiero que a medida que se implementen las cosas se documente a la vez en el ers."
- S5. Constraints from `CLAUDE.md` and `docs/stack.md` apply: project created with `npx sv create`, SvelteKit 3 + Svelte 5 + TS,
  alias `#lib`, Tailwind v4, adapter Cloudflare, schema `app`, Supabase CLI SQL migrations as the single source of truth,
  `schema.ts` generated by `drizzle-kit pull`, every write through `withActor`, each migration with its pgTAP test,
  `lint`, `typecheck`, tests and `build` green before closing.
